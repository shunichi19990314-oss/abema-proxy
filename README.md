# ABEMA Reverse Proxy

ABEMA用のシンプルなリバースプロキシです。

## 重要な注意

- **ヘッダー偽装だけでは地域制限は突破できません**
- 無料公開プロキシはほぼ使えません（すぐ死ぬ・ブロックされる）
- 安定して使いたい場合は **日本のプロキシ** か **日本VPS** が必要です

---

## 使い方

### 1. そのままデプロイ（ヘッダー偽装のみ）

特に設定しなくても起動します。  
ただし地域制限はほぼ解除されません。

### 2. 有効なプロキシを使う場合（推奨）

Railway の Variables に追加：

```env
PROXY_LIST=http://ユーザー:パス@日本プロキシのIP:ポート
```

複数ある場合はカンマ区切りで指定できます。

---

## 環境変数

| 変数名 | 説明 | デフォルト |
|--------|------|-----------|
| `PORT` | ポート | `3000` |
| `TARGET` | プロキシ先 | `https://abema.tv` |
| `PROXY_LIST` | 上流プロキシ（カンマ区切り） | なし |
| `SPOOF_IP` | 偽装IP | `126.0.0.1` |
| `SPOOF_COUNTRY` | 偽装国コード | `JP` |

---

## エラーが出る場合

`Error occurred while trying to proxy` が出る主な原因：

1. 有効な上流プロキシが設定されていない
2. 設定したプロキシが死んでいる
3. ABEMA側が接続を拒否している

**対策**  
動く日本プロキシを `PROXY_LIST` に設定してください。
