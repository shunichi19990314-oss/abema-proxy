# ABEMA Reverse Proxy for Railway

Simple Node.js reverse proxy to access ABEMA (https://abema.tv) via Railway.

## Deploy to Railway

1. Click the button below or connect this repo to Railway
2. Deploy
3. Generate a public domain in Settings → Networking

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template)

## Local run

```bash
npm install
npm start
```

## Notes

- ABEMA has strong anti-bot and geo-restrictions. This may not work fully for video playback.
- Use at your own risk. May violate ABEMA Terms of Service.
