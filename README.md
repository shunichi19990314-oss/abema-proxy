# ABEMA Reverse Proxy (Free Public Proxy Edition)

無料の公開プロキシを自動取得・ローテーションしてABEMAにアクセスするリバースプロキシです。

> **注意**  
> 無料公開プロキシは非常に不安定です。すぐに死んだり、ABEMAにブロックされたりします。  
> あくまで実験用です。安定して使いたい場合は有料の日本住宅プロキシか日本VPSを推奨します。

---

## 特徴

- 無料の日本プロキシを自動取得（ProxyScrape / GeoNode など）
- リクエストごとにプロキシをローテーション
- 手動でプロキシを指定することも可能
- `/health` と `/proxies` で状態確認可能

---

## 使い方（Railwayなど）

### 1. そのままデプロイ
特に設定しなくても起動時に無料プロキシを自動取得します。

### 2. 手動でプロキシを指定したい場合

Environment Variables に以下を追加：

```env
PROXY_LIST=http://1.2.3.4:8080,socks5://5.6.7.8:1080,http://9.10.11.12:3128
```

カンマ区切りで複数指定できます。手動指定分が優先されます。

### 3. 動作確認

- `/health` … プロキシ数や状態を確認
- `/proxies` … 現在ロードされているプロキシ一覧

---

## 環境変数

| 変数名 | 説明 | デフォルト |
|--------|------|-----------|
| `PORT` | リッスンポート | `3000` |
| `TARGET` | プロキシ先 | `https://abema.tv` |
| `PROXY_LIST` | 手動プロキシ（カンマ区切り） | なし |

---

## 注意事項（重要）

- 無料公開プロキシは**信頼性が非常に低い**です
- ABEMAはプロキシ検知が厳しいため、ほとんどの無料プロキシは弾かれます
- 動作してもすぐに使えなくなる可能性が高いです
- セキュリティ面でもリスクがあります（通信内容がプロキシ運営者に見える可能性）

安定して使いたい場合は：
1. 有料の日本住宅プロキシを使う
2. Oracle Cloudなどの日本VPSに直接デプロイする

のどちらかを強く推奨します。
